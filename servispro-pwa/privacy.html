Dasar Privasi ServisPro

Kemas kini terakhir: 6 Ogos 2026

ServisPro ("Aplikasi") ialah perisian pengurusan bengkel kenderaan. Dasar ini menerangkan data apa yang dikumpul, sebab ia dikumpul, dan bagaimana ia disimpan — untuk kedua-dua jenis pengguna Aplikasi: staf bengkel yang log masuk untuk mengurus operasi, dan pelanggan bengkel yang secara pilihan (tidak wajib) mendaftar akaun untuk melihat sejarah servis mereka sendiri.

1. Data yang Dikumpul

Staf bengkel (perlu log masuk):

  • Nama, alamat e-mel, dan peranan (cth. Admin, Mekanik) — dimasukkan oleh pentadbir bengkel
  • Rekod kehadiran (waktu clock-in/clock-out) jika ciri Kehadiran digunakan
  • Aktiviti dalam Aplikasi (log audit ringkas — cth. "Tambah Item", "Ubah Harga") untuk tujuan jejak dalaman bengkel

Pelanggan bengkel (data dimasukkan oleh staf sebagai sebahagian rekod perkhidmatan, ATAU secara langsung jika pelanggan mendaftar akaun pilihan):

  • Nama dan nombor telefon
  • Butiran kenderaan (no. plat, model)
  • Sejarah kerja, sebut harga, invois, dan janji temu servis
  • Jika mendaftar akaun pilihan: alamat e-mel dan kata laluan (disulitkan, tidak pernah disimpan sebagai teks biasa)
  • Gambar kenderaan yang dimuat naik oleh staf semasa pemeriksaan (jika berkenaan)

Data peranti (jika ciri notifikasi push diaktifkan):

  • Kelayakan langganan push (push subscription) peranti — tiada maklumat peribadi terkandung di dalamnya, hanya alamat teknikal untuk menghantar notifikasi

2. Bagaimana Data Digunakan

Semata-mata untuk menjalankan fungsi bengkel: menjejak kerja/inventori/invois, menghantar notifikasi/pautan berkaitan servis (cth. laporan pemeriksaan, resit, status kad kerja) kepada pelanggan yang berkenaan, dan membolehkan staf bengkel mengurus operasi harian. Data tidak digunakan untuk pengiklanan, dan tidak dijual kepada mana-mana pihak ketiga.

3. Perkongsian Data

Data disimpan pada infrastruktur Supabase (pangkalan data Postgres terurus), yang bertindak sebagai pemproses data bagi pihak bengkel. Data tidak dikongsi dengan mana-mana pihak ketiga lain untuk tujuan pemasaran atau jualan. Setiap bengkel yang menggunakan Aplikasi ini mempunyai pangkalan data sendiri yang berasingan — data satu bengkel tidak boleh diakses oleh bengkel lain.

4. Keselamatan

Akses dikawal melalui Row Level Security (RLS) di peringkat pangkalan data — akaun pelanggan (jika didaftarkan) hanya boleh melihat rekod milik mereka sendiri, tidak pernah rekod pelanggan lain atau data pentadbiran staf. Kata laluan disulitkan menggunakan piawaian industri (bcrypt, melalui Supabase Auth) dan tidak pernah kelihatan oleh sesiapa, termasuk pembangun Aplikasi.

5. Hak Anda

Pelanggan bengkel boleh memohon bengkel berkenaan untuk membetulkan atau memadam rekod mereka pada bila-bila masa. Staf bengkel boleh menghubungi pentadbir bengkel masing-masing untuk sebarang permintaan berkaitan data peribadi.

6. Kanak-Kanak

Aplikasi ini ditujukan untuk kegunaan perniagaan (bengkel servis kenderaan) dan tidak direka atau ditujukan untuk kanak-kanak bawah umur 13 tahun.

7. Perubahan Dasar

Dasar ini mungkin dikemas kini dari semasa ke semasa. Sebarang perubahan akan disiarkan di halaman ini dengan tarikh kemas kini terbaharu.
